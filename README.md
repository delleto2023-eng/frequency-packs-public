# Healing Frequency Music Packs 🎵

**Complete drag-and-drop package of healing frequency music, binaural beats, drum samples, and 300-500 open-source sound effects.**

All content is **free, open-source, CC0/public domain, and royalty-free** for personal and commercial use.

## 📦 What's Included

### 1. **Healing Frequencies (432 Hz, 528 Hz, 741 Hz, 852 Hz, 963 Hz)**
- Individual drum samples locked to each frequency
- Full ambient/music tracks (5-15 min loopable)
- Binaural beats with isochronic tones
- Mixed with hi-hats, kicks, snares, and other percussion

### 2. **Open-Source Sound Library**
- **300-500 royalty-free sound effects**
- Organized by category:
  - Drums & Percussion (100+ samples)
  - Ambient & Nature (100+ samples)
  - Sound Effects & Foley (100+ samples)
  - Synth & Electronic (50+ samples)
- All sourced from: Freesound, Zapsplat, OpenGameArt, CC0 libraries

### 3. **Generation Scripts**
- Python scripts to generate your own binaural beats
- Customizable drum kit generators
- Batch processing for multiple frequencies

## 🚀 Getting Started

### Option A: Use Pre-Generated Packs (Recommended)
1. Navigate to `/healing-frequencies/` folder
2. Choose your desired frequency (432Hz, 528Hz, etc.)
3. Select track type:
   - `drum-samples/` - Individual drum hits
   - `binaural-tracks/` - Binaural beats only
   - `mixed-ambient/` - Full music with drums + tones
4. Drag and drop into your audio player or DAW

### Option B: Generate Your Own
1. Install Python 3.8+
2. Navigate to `/generation-scripts/`
3. Run: `pip install -r requirements.txt`
4. Execute: `python generate_binaural.py --freq 432 --duration 600`
5. Output goes to `/healing-frequencies/`

### Option C: Use Sound Library
1. Browse `/sound-library/` by category
2. Drag samples into your DAW or music production software
3. License info in `/documentation/licensing.md`
